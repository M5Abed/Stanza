Stanza - Suggested Features Roadmap
=======================================

1. TRUE OFFLINE MODE (DOWNLOADS)
   - Description: Use the bundled yt-dlp.exe to save songs locally.
   - Benefit: Listen to music without an internet connection.
   - Implementation: Add a "Download" button to song menus and save to a local folder.

2. AMBIENT UI (DYNAMIC COLORS)
   - Description: UI background and accents change color based on the current album art.
   - Benefit: Premium, immersive aesthetic similar to Apple Music/Spotify.
   - Implementation: Use ColorThief to extract dominant colors from images in the frontend.

3. AUDIO VISUALIZER
   - Description: Real-time visual representation of the audio frequencies.
   - Benefit: High "wow" factor and visual engagement.
   - Implementation: Web Audio API (AnalyserNode) + Canvas/SVG in the renderer.

4. AUTO-UPDATING ENGINE
   - Description: Automatically check for and download yt-dlp updates.
   - Benefit: Ensures the app never stops working when YouTube changes their site code.
   - Implementation: Background task running "yt-dlp.exe -U" periodically.

5. MINI-PLAYER / COMPACT MODE
   - Description: A small, "Always on Top" window with minimal controls.
   - Benefit: Control music while working in other applications without the full UI.
   - Implementation: Toggle window size and "alwaysOnTop" property in Electron.

6. LAST.FM SCROBBLING
   - Description: Sync listening history to a user's Last.fm account.
   - Benefit: Users can track their long-term listening statistics.
   - Implementation: Send a POST request to Last.fm API when a song reaches 50% completion.
